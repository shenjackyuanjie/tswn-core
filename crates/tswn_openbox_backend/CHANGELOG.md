# 更新日志

## [Unreleased] - 0.4.7

### 新增

- `ResultUpdate` 增加 `legacy_log` 与 `legacy_log_authoritative`，并提供 `new_with_legacy`：增量结果可同时携带与旧输出一致的文本块，
  供纯文本视图直接显示；结构化字段与既有公开入口保持兼容，该文本计入有界队列预算。

### 修复

- 批量胜率：修复关闭「每组胜率」时仍产生明细，以及带权镜像的详情顺序与旧输出不一致的问题。
- 配队：队友改为和选手一样按“逐个成员单独构建”冻结成 `+ol` 后再组队；此前只冻结选手，
  同公会（`@队名` 相同）的队友会单方面吃到组队加成，带权队友 TOML 里的普通名字必然命中，
  使该队友组合的 cqp 偏高。已经带 `+diy` / `+ol` 的队友输入保持原样，日志与文件标签仍是原始输入行。
- 配队：最终排序与求和只计算一次，同时供文件输出与文本日志使用；实时加权汇总在窗口内复用已完成组合，取消后不再把缺失组合当作 0 分。
- 评分：复用高亮判定；没有文本消费者时跳过技能榜的重复格式化。

### 性能

- 导出详情每行只生成一次文本块，`*_observed` 且不写文件时不再累积整份输出。
- 导出结果的详情只以旧版文本块给出，不再额外生成一份逐项结构化条目；界面直接按该文本逐行渲染，属性与技能顺序与 CLI 输出一致。

### 验证

- 新增对照测试：四类任务的 `*_observed` 文本与旧 API 逐字节一致，覆盖 DIY 的详情开关与 `--old` / `--minions`、
  胜率的阈值与高亮筛选、镜像详情顺序、关闭每组胜率、配队的 `none` / `top` / `every` 与各阈值、
  评分的指标阈值与技能榜全部过滤，以及 0 分阈值等号边界。
- 新增配队冻结回归测试：普通队友与带权队友（TOML）两条路径、选手与被加成方互换、一行多名成员三种情形，
  逐项断言选手与队友在队伍里的属性与技能都等于各自单独构建，且标签仍是原始输入行。
- `cargo test -p tswn_openbox_backend`：52 通过；`cargo +nightly fmt --check` 无输出。

### 说明

- 面向界面的增量字段仍只描述结构化结果；旧版文本字段用于兼容既有纯文本输出，不影响文件输出与 CLI 行为。

## [0.4.6] - 2026-09-30

### 新增

- 从 `tswn_openbox` 提取共用计算后端与预设，提供独立的无界面 Rust library；Openbox GUI、
  `openbox-cli` 和 DS4 直接复用，不依赖 `eframe`／`egui`，消除 Openbox 与 DS4 的循环依赖。
- 提供 `backend` 与 `presets` 模块，保留 `to-diy`、`namer-pf`、批量胜率和配队任务入口、
  参数／进度类型及 `*_observed` 增量事件接口；迁移原有解析、文件输出、技能榜与矩阵执行逻辑。
- 提供 `load_target_presets_from_root()`，按指定工作目录读取预设并补齐缺失的内嵌默认资源，
  不覆盖用户文件；保留带权靶子与队友配置的解析和加载接口。

### 兼容性

- `tswn_openbox::backend` 与 `tswn_openbox::presets` 通过再导出保留旧公开路径；输出格式、
  加权计算、稳定排序与取消语义不变，相关业务回归测试随实现迁移到本 crate。

### 说明

- 本轮首次封板为 `0.4.6`，与 Openbox 同步；提取时的 `0.4.5` 未作为独立版本发布。
- 提取前的功能与性能变更记录见 `../tswn_openbox/CHANGELOG.md`；本日志从拆分开始记录。

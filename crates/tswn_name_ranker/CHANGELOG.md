# 更新日志

## [Unreleased] - 0.1.1

## [0.1.0] - 2026-09-30

### 新增

- 新增 `tswn_name_ranker` 独立排名服务，提供基于 `axum` 的 Web API 和静态管理界面；默认监听
  `127.0.0.1:3001`，可通过 `NAME_RANKER_BIND` 调整监听地址。
- 新增 SQLite 持久化层，支持名称导入、靶子导入、加权两两胜率缓存、排名结果、合作对象明细、
  归档名称与运行元数据；数据库路径可由 `NAME_RANKER_DB` 配置。
- 新增名称解析与角色构建流程，保存 `tswn_core` 导出的 DIY 及 Text-Type；支持手动标记扩展名称、
  单名称补测缺失合法边，并提供重算状态、结果查询和文本导出接口。
- 新增靶子权重评分：按导入靶子集合调用 `tswn_core` 胜率接口计算名称组合矩阵，缓存固定 10000
  局样本并按权重聚合。
- 新增带合法边约束的迭代排名模型，输出分数、系数、强度、收敛与可靠性指标，并按低分或可用伙伴
  不足自动归档名称；重算支持并发 worker 和跳过已归档名称。
- 新增内置 ABCP 方向校准器及外部 `abcp5` 补算流程，用于筛选合法名称对、补齐新增名称的 ABCP
  结果并在结果明细中输出合法合作对象。

### 调整

- 名称构建改为复用 `tswn_core` 已构建角色与 `cli_api::to_diy_prepared` 导出接口，避免重复解析，
  并在核心接口变更后同步适配新的 `PreparedPlayer` 流程。
- Text-Type 计算增加版本标记，服务启动时会按当前规则刷新已有名称的分类结果。

### 移除

- 移除废弃的拟合搜索链、无调用的诊断字段及旧校准辅助逻辑，保留当前排名、ABCP 校验和兼容数据
  结构。

### 依赖更新

- 新增独立 `Cargo.lock`，锁定清单兼容范围内的依赖版本。
- 同步 `tswn_core 0.7.0` 及 encoder 引入的 `sha2` 传递依赖，独立锁文件与当前核心依赖保持一致。

### 说明

- 该 crate 为内部 Web 工具，本轮首次封板为 `0.1.0`；因依赖独立校准数据，
  已从主 workspace 排除，使用本 crate 的 `Cargo.toml` 与独立 `Cargo.lock` 构建，不参与工作区默认构建与测试。

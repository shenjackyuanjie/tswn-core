# 曙光（smdd）Boss

输入 `smdd@!` 召唤「曙光」。属性与 Squall 完全一致：攻、防、敏、魔、抗、智 106，HP 360，MP 53；**106 是外显值，实际战斗速度按普通公式补 160 为 266**。显示名“曙光”，图标固定用 `nan@nan`。

## 技能

「开始做局」是始终激活的被动：每个自身行动 +1 层「局」（上限 8），被敌方本体命中也会 +1。其余 7 个技能按行动次数 `turn % 7` 轮转：

| 技能 | 行为 | 台词／出处 |
| --- | --- | --- |
| 抛开事实不谈 | 全属性 ×1.25，最多叠 2 层。 | 我 rp 神 |
| 虎星恒等式 | 召唤 Gordon（`RLHTKAZRMFFJ@nan`）与两只笑面虎（`my7CAxNHHz@XJ联队`、`2LRLYnOw5pmmhXG@XJ联队`）加入己方；两只 XJ 联队统一使用 `XJ联队@XJ联队` 的图标。 | 本队单双人都一堆 |
| 卿言猴儿 | 十连击，每击 90% 攻击。 | 唉，乱杀 |
| 孤常卖牢 | 召唤猎豹（🐆 图标），极高速度与敏捷。 | 猎豹不彻底等于彻底不猎豹 |
| 矿机测号 | 随机敌方角色除智力外属性减半，智力变为 36。 | 神人，评价是弱智 |
| 赢 | 按敌方人数连续普攻 1~5 次，每次回避率固定 50%。 | 单人组：赢 |
| 可能我是名竞之神 | 随机三选一：大额伤害／回复 25% HP／速度 +40。 | 随机数处理好再跑只用花 eps 时间 |

卷测速与平A到底已移除。

## 验证

`crates/tswn_core/src/runtime/combat/boss_smdd_tests.rs` 覆盖固定数值（含外显速度与 266 实际速度）、`nan@nan` 图标映射与七技能轮转。

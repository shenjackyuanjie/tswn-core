# 曙光（smdd）Boss

输入 `smdd@!` 召唤「曙光」。属性与 Squall 同档：攻、防、敏、魔、抗、智 106，HP 360，MP 53；速度为 160（比 Squall 快，保证十个技能在一场里能轮转完）。显示名“曙光”，图标固定使用 `nan@nan`。

技能全部取自群成员 3023226682（被做局者）在 namerena 群里的原话，按其说话风格分成十种：

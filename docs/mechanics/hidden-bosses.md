# 暂时隐藏的自定义 Boss 规格（供改版参考）

以下 5 个 Boss 目前只在挑战下拉里隐藏（`index.html` 中注释掉），代码、文档与手动输入 `名称@!` 全部保留。
所有数值以当前代码为准（`crates/tswn_core/src/runtime/combat/boss_*.rs`）。

## 通用约定

- 属性档：攻/防/敏/魔/抗/智 = 106，HP = 360，MP = 53；**106 是外显速度，实战速度 266**（普通公式 +160）。
- 名称系数 0，不受普通名字加成；与其他 Boss 一样有兜底免疫：净化类 84/256、控制类 192/256 概率免疫。
- 技能选择：Squall 之后的自定义 Boss 均按**随机**选技能（非固定轮转），有前置条件的技能需要满足条件才会进池。
- 攻击类伤害统一走 `get_at()` 的 ATP 口径，与同攻击力普通攻击一致，不再直接拿 attack/magic 当 ATP。
- 图标：boss 用专属映射（见各节），召唤物用自带图标键。

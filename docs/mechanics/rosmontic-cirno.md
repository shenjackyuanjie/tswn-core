# 琪露诺（cirno@!）反编译规格

来源：Rosmontic/namerena 的 md5.js（Dart2JS 产物，类 `T.cirno` / `T.tha5*`）。

## 属性

Rosmontic 的属性表是**相对基准的增量**，基准为
`[91, 73, 103, 99, 120, 90, 90, 323]`（攻/防/速/敏/魔/抗/智/HP）。

- Squall: `[15,33,3,7,-14,16,16,37]` → 106/106/106/106/106/106/106/360（与现有实现一致，验证了基准）
- cirno: `[-6,29,16,17,29,1,57,575]` → **85 / 102 / 119 / 116 / 149 / 91 / 147 / 898**

## 技能（5 个）

| 技能类 | 名称 | 行为 |
| --- | --- | --- |
| tha5b1 | 冰免疫（被动） | 受到冰属性伤害时改为 0，并播报 `[0][免疫]冰冻伤害` |
| tha5n1 | 冰符「冰瀑」 | 单体 110% 冰属性伤害；目标处于冰冻时伤害 ×1.3 |
| tha5n2 | 雪符「钻石风暴」 | 群体 70% 冰属性伤害；每个冰冻目标让后续伤害 ×1.3（原实现会累积） |
| tha5n3 | 冻符「完美冻结」 | 3 段，各约 40% 魔法伤害并尝试附加冰冻；命中判定用 `100 + 魔` 对 `抗 + 敏` |
| tha5s1 | 冻符「绝对零度」 | 群体 99% 冰属性伤害，并尝试附加冰冻 |

技能触发权重：tha5b1 为常驻被动；tha5n1/tha5n2/tha5n3 的 `f` 分别是 55/60/60；tha5s1 的 `f=90` 且**每次使用后自身 `f`-10**（越用越少）。

# 琪露诺（cirno@!）

参考版本为 Rosmontic/namerena 提交 2ff2bbb700d3e42c0293c870277efa7fd2ab3aa2 的根目录 md5.js。提取工具：scripts/rosmontic/extract-reference.cjs。

初始化后的攻、防、速、敏、魔、抗、智、HP 为 44、39、214、44、45、54、63、810。速度包含行动条基值 160。属性增量叠加在名字派生值上，不能统一叠加某个固定基准。

技能按初始化后的技能顺序逐项判定，而非加权抽取。蓝量足够时消耗随机 8～23 MP；未发动技能时使用普通攻击。

| 技能 | 概率等级 | 机制 |
| --- | --- | --- |
| 冰伤免疫 | 被动 | 冰属性伤害归零；不等于免疫冰冻状态 |
| 冰符「冰瀑」 | 55 | 物理威力 ×1.1，按魔抗结算；冰冻目标再乘 1.3 |
| 雪符「钻石风暴」 | 60 | 至多三个目标，魔法威力 ×0.7；每个冰冻目标使本次及后续伤害累计乘 1.3 |
| 冻符「绝对零度」 | 初始 90 | 至多九个目标，魔法威力 ×0.99；冰冻目标累计乘 1.6。使用后概率等级减十、魔力加九、智慧整除十一 |
| 冻符「完美冻结」 | 60 | 同一目标至多三段魔法威力 ×0.4，冰冻时乘 1.3；命中用自身敏捷加 100 对目标抗性加敏捷；回避后结束连击 |

上述攻击均不额外附加冰冻。每次概率判定比较随机字节低七位与等级。新战斗恢复绝对零度等级，回放快照保留其当前等级。

图标来自同一参考文件内嵌的原始 16×16 PNG，参见 assets/rosmontic-boss-icons/manifest.json。

# 新纪元（xjy）Boss

输入 `新纪元@!` 挑战。属性与 Squall/曙光同档：攻、防、敏、魔、抗、智 106，HP 360，MP 53；外显速度 106，实战速度 266。图标固定用 `新纪元@新纪元`。

## 技能

| 技能 | 行为 |
| --- | --- |
| 谁还没几个猎豹 | 敌方（含召唤物）人数多于己方时发动，连续召唤猎豹，直到己方含召唤物的总人数达到对方的两倍。 |
| 一堆人海cqp60 | 对敌方全体造成 60 点无视防御伤害，可被闪避，不触发反击、反弹、防御与守护。 |
| 我 rp 大 / 组队好 / xp 还 6 | 每次发动随机取其中两个：全属性 +20%；召唤一个分身；敌方全体全属性 -6。 |
| 我似乎确实有些猎豹了 | 场上有猎豹时，随机选一只猎豹全属性 ×2。 |
| 我将制霸 / 我是神 / 因为很神 / 我重开了 / 我赢了好多 | 随机取一个名字发动：两回合铁壁（受伤 ×0.6）、+100 护盾、两回合攻魔 ×2。 |
| 他动不动拜谢我，其实是一种看不起我的表现 | 随机敌方进入拜谢两回合，期间攻击与魔力为 0。 |
| 那是因为我就是豹 | 自身体力低于猎豹时，召唤一只猎豹并与其交换体力。 |

## 验证

`crates/tswn_core/src/runtime/combat/boss_xjy_tests.rs` 覆盖固定数值、`新纪元@新纪元` 图标与猎豹补员。

# 被子（quilt）Boss

输入 `quilt@!` 召唤后排 Boss「被子」：HP 500，攻、防、速、敏、魔、抗、智均为 100，速度不追加普通名字的 160 点。本体不攻击，也无法被直接伤害：命中它一律结算为 0，只有衍生物传导的伤害才会扣它的血。

## 本体技能

| 技能 | 行为 |
| --- | --- |
| 钻出被子 | 从被子里钻出一只猴区（`猴区 #x`）。猴区攻、魔 130，防、抗 55，HP 260。 |
| 多重魂 | 至少两只在场时可合并，最多合并三只。新实体使用新的全局编号，沿用最小编号猴区的睡眠计数。 |
| 猴区宣布占领此群。 | 猴区达到 6 只后在被子行动时发动，对全体敌方角色施加减速；战报主语是“猴区”。 |
| 鱼我所欲也 | 场上没有鱼且已有至少 1 只猴区时，从被子里钻出一条鱼（`鱼 #x`）。鱼攻、魔 70，防、抗 110，HP 320，嘲讽明显低于猴区。 |

衍生物与本体之间通过 `DamageSharePolicy::ShareToOwner` 连接：衍生物受到的伤害有一半转给被子（向下取整）。

## 衍生物技能

- 睡5觉：第 5、10、15……次自身行动固定发动，无 MP 门槛。受到的伤害为 0，直至下一次行动开始。
- 逮捕：对目标挂上与魔力挂钩的持续伤害，独立结算三次，随后这只猴区消失。
- 得意猴区：每层使速度增加 10%、攻击威力增加 15%，持续两次自身行动，独立叠加，可被净化解除。
- houqu -twin stroke of the end-： 召唤一只克隆体并吞噬原本的猴区。
- HOUQU_BLAST：被击倒时按概率分裂成两只更小的猴区，子体不再继续分裂。
- 猴儿冰冻：冰冻解除时立即钻进被子，持续到下次行动（受击为 0）。
- 鱼·睡5觉：同猴区。
- 鱼·上睡觉掀开被子全都是猴区：钻被一回合，下次行动钻出一只猴区；与「睡5觉」合计钻被 3 次后触发用进废退。
- 鱼·さかなホチ恋の歌：有猴区时对全体猴区造成微量伤害并叠一层得意。
- 鱼·被飞翔猴区逮捕了：给自己挂一层低伤害的持续伤害，并让所有同属猴区在鱼存活期间受到的伤害降低 25%。
- 用进废退：钻被满 3 次的鱼变成猴区，保留当前属性与状态。

## 验证

`crates/tswn_core/src/runtime/combat/boss_quilt_tests.rs` 覆盖固定数值、召唤与分摊、本体不可选中、多重魂合并；衍生物技能在 CLI 对局中按回合计触发（睡5觉／逮捕／得意／HOUQU_BLAST 均可在日志中看到）。

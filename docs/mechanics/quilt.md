# 被子（quilt）Boss

输入 `quilt@!` 召唤后排 Boss「被子」：HP 500，攻、防、速、敏、魔、抗、智均为 100，速度不追加普通名字的 160 点。本体不攻击，也无法被直接伤害：命中它一律结算为 0，只有衍生物传导的伤害才会扣它的血。

## 本体技能

| 技能 | 行为 |
| --- | --- |
| 钻出被子 | 从被子里钻出一只猴区（`猴区 #x`）。猴区攻、魔 130，防、抗 55，HP 120。 |
| 多重魂 | 场上猴区达到 2 只且回合数满足时，把其中两只的属性叠加到一只身上，另一只消失，并重新编号。 |
| 猴区宣布占领此群。 | 猴区达到 3 只以上且回合数满足时发动，对全体敌方角色施加减速；战报主语是“猴区”。 |
| 鱼我所欲也 | 场上没有鱼且已有 2 只猴区时，从被子里钻出一条鱼（`鱼 #x`）。鱼攻、魔 70，防、抗 110，HP 150，嘲讽明显低于猴区。 |

衍生物与本体之间通过 `DamageSharePolicy::ShareToOwner` 连接：衍生物受到的伤害有一半转给被子（向下取整）。

## 图标

被子、猴区、鱼分别使用 🛏️、🐒、🐟 的 emoji 图标，由前端按 `id_key_name`（`quilt`、`quilt-monkey`、`quilt-fish`）绘制，不走默认的名字生成图标。

## 衍生物技能

- 睡5觉：每 5 回合固定发动一次，本回合不行动且受击为 0，下次行动时醒来。
- 逮捕：对目标挂上与魔力挂钩的持续伤害（沿用投毒状态），随后这只猴区消失。
- 得意猴区：给自己叠加速与聚气，可反复叠层，可被净化解除。
- houqu -twin stroke of the end-： summon 一只克隆体并吞噬原本的猴区。
- HOUQU_BLAST：被击倒时按概率分裂成两只更小的猴区，子体不再继续分裂。
- 猴儿冰冻：冰冻解除后的下一次行动钻进被子一回合（受击为 0）。
- 鱼·睡5觉：同猴区。
- 鱼·上睡觉掀开被子全都是猴区：钻被一回合，下次行动钻出一只猴区；累计 3 次后触发用进废退。
- 鱼·さかなホチ恋の歌：有猴区时对全体猴区造成微量伤害并叠一层得意。
- 鱼·被飞翔猴区逮捕了：给自己挂一层低伤害的持续伤害，并标记飞翔状态。
- 用进废退：钻被满 3 次的鱼变成猴区，保留当前属性与状态。

## 验证

`crates/tswn_core/src/runtime/combat/boss_quilt_tests.rs` 覆盖固定数值、召唤与分摊、本体不可选中、多重魂合并；衍生物技能在 CLI 对局中按回合计触发（睡5觉／逮捕／得意／HOUQU_BLAST 均可在日志中看到）。

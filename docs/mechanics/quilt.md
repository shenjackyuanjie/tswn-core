# 被子（quilt）Boss

输入 `quilt@!` 召唤后排 Boss「被子」：HP 500，攻、防、速、敏、魔、抗、智均为 100，速度不追加普通名字的 160 点。本体不攻击，也无法被直接伤害：命中它一律结算为 0，只有衍生物传导的伤害才会扣它的血。

## 本体技能

| 技能 | 行为 |
| --- | --- |
| 钻出被子 | 从被子里钻出一只猴区（`猴区 #x`）。猴区攻、魔 130，防、抗 55，HP 120。 |
| 多重魂 | 场上猴区达到 2 只且回合数满足时，把其中两只的属性叠加到一只身上，另一只消失，并重新编号。 |
| 猴区宣布占领此群。 | 猴区达到 3 只以上且回合数满足时发动，对全体敌方角色施加减速；战报主语是“猴区”。 |
| 鱼我所欲也 | 场上没有鱼且已有 2 只猴区时，从被子里钻出一条鱼（`鱼 #x`）。鱼攻、魔 70，防、抗 110，HP 150，嘲讽明显低于猴区。 |

衍生物与本体之间通过 `DamageSharePolicy::ShareToOwner` 连接：衍生物受到的伤害有一半转给被子（向下取整）。

## 图标

被子、猴区、鱼分别使用 🛏️、🐒、🐟 的 emoji 图标，由前端按 `id_key_name`（`quilt`、`quilt-monkey`、`quilt-fish`）绘制，不走默认的名字生成图标。

## 当前实现范围

已实现：本体数值与身份、不可被直接伤害、猴区/鱼召唤、多重魂合并、占领减速、半伤传导、emoji 图标。

尚未接入：猴区的睡5觉、逮捕、克隆吞噬、得意、HOUQU_BLAST 分裂、猴儿冰冻，以及鱼的睡觉钻被、さかなホチ恋の歌、被飞翔猴区逮捕、用进废退。这些需要分别接入受击、死亡、状态解除与行动调度的钩子，留待后续单独实现。

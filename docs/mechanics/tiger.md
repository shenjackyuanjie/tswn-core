# TigerStar（豹星）Boss

输入 `TigerStar@!` 挑战。属性与 Squall 同档：攻/防/敏/魔/抗/智 106、HP 360、MP 53；外显速度 106，实战 266。

| 技能 | 行为 |
| --- | --- |
| 草你 | 随机敌方承受一次无法回避的 100% 魔攻，MP -64，并附加魅惑。 |
| 我是M | 两回合内受伤时，随机一项属性提升等同于伤害的数值。 |
| 全在搞我 | 敌方全体魅惑一回合。 |
| 拜谢者，出神豹 | 随机敌方获得拜谢压制（回蓝减半），并召唤一只猎豹。 |
| 我豹了 / 对的对的直接抬走猎豹 | 有猎豹时，一只猎豹自爆，伤害固定为自身魔力的 400%。 |
| 红温 | HP 低于 50% 时全属性 ×1.5，持续整场。 |
| 幻术 | 召唤幻影（沿用引擎幻术，属性与本体同源）。 |
| 显得我小 | 分身一次，技能熟练度保持不变。 |
| 豹星刚刚 猎豹了 | 随机召唤 1~3 只猎豹。 |
| 加成之后完全恐怖 | 全属性 +10%，可叠加。 |

第 10 个技能名取自群成员 2128152357 的原话「加成之后完全恐怖」（2025-12-08 21:56:53）。

## 验证

`crates/tswn_core/src/runtime/combat/boss_tiger_tests.rs` 覆盖固定数值与草你/我是M。

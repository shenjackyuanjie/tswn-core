# 咦（yi）Boss

输入 `咦@!` 挑战。属性固定：HP 487、攻 99、防 87、敏 82、魔 98、抗 89、智 89；外显速度 89，实战速度 249。图标直接使用 `C:\Users\xiong\Downloads\352.png` 的原图（128×128），由浏览器缩放到图标尺寸，不再压成 32×32。

## 技能

| 技能 | 行为 |
| --- | --- |
| 咦拜涂地 | 首次行动必定发动并召唤两只拜谢；之后随机发动，每次召唤一只。播报“拜谢从虚空中出现了”。 |
| 咦？ | 成功闪避攻击后说一声“咦”，并对 1~x-2 名敌人反击（x 为含召唤物的敌方人数）。 |
| 猴咦射日 | 一次 150% 魔攻；每发动一次自身攻击力永久 +50%。 |

## 拜谢（衍生物）

HP 356、攻 76、防 99、速 68、敏 69、魔 78、抗 98、智 56。

- 只会使用「！？拜拜？！」：每次行动随机对 1~2 名尚未被自己拜谢过的敌人扣 20 MP，并标记；被标记的角色自然回蓝减半，直到这只拜谢死亡。
- 若全场敌人都已被拜谢过，改为给咦回血。

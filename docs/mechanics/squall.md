# Squall 科研 Boss（重制）

输入 Squall@!，或在右侧挑战 Boss 四列表格中选择 Squall。初始攻、防、敏、魔、抗、智均为 106；外显速度 106，实战速度 266；HP 360，MP 53。图标继续使用 Squall@Squall。

| 技能 | 行为 |
| --- | --- |
| 开始测试 | 每个敌方本体实际行动结束后各获得 1 层样本，上限 6；召唤物不给样本。根据敌方对己方造成的实际生命损失记录重点研究对象。 |
| 建立模型 | 消耗 2 层样本，三次独立魔法攻击，各为普通魔攻 174%；前两次优先重点对象，第三次另一个敌方本体，死亡后重选。 |
| 发布测号器 | 全体在场存活角色（不分敌我）速度 +50；若下次自身行动开始时尚未红温，自动触发红温。 |
| 三人科研 | 每场一次，召唤高位辅助与低位配件，各 168 HP、212 速、128 其余属性。辅助高嘲讽，配件 200 级潜行；保留铁壁/守护及弱化群攻/减速的助手分工。 |
| 再卖弱把你头薅下来 | 选择敌方当前七围总和最高的角色，七围全部减半，并吸取其当前剩余 HP 的一半，回复量不超过自身最大 HP。不加入 TigerStar 特判。 |
| 开喷 | 随机选取敌方半数角色，人数向上取整；分别造成 152% 物理攻击与 76% 魔法攻击。 |
| 我就端这么个东西上来你爱用不用 | 消耗所有样本，每层独立选择一个敌方目标，造成 120% 魔法攻击，强命；仍结算防御、护盾、反弹与死亡。 |
| 暴政一下 | 随机 1～3 个敌方角色 MP 设为 -64、行动条减 2048、附加 4096 点冰冻标记，自身攻击 +30。 |
| 红温 | HP 严格低于 50% 时立即自动触发，七围永久 ×1.5，不叠加、不占行动，净化不可解除；发布测号器也可触发。 |
| 出勤 | 固定占用第一次实际行动，获得 100 点护盾，防、抗 ×2，持续到第二次实际行动结束。护盾沿用引擎普通护盾规则。 |
| 正在出勤回来的路上 | 固定占用第二次实际行动；50% 概率己方加入 1～2 只猎豹，另外 50% 不召唤，不改放其他技能。 |

“回合”在出勤与测号器倒计时中指 Squall 本体真正获得的行动，冰冻跳过不推进。第二次行动结束仅解除出勤双防，未消耗的护盾保留。

第二次行动之后，在满足样本/一次性条件的主动技能中随机选择，不再使用旧版冷却、误解需求、嘲讽交换、剪枝、烧库自损或聚气治愈。

技能发动后的台词暂时隐藏，原句保留在代码中，技能名称、状态、伤害和召唤提示正常显示。展示开关不消费或改变战斗随机数。

技能伤害、召唤与死亡均使用正式战斗链。专属属性变化、样本、出勤与测号器倒计时随快照复制，新战斗重置；回放与无帧批量模拟共享同一套机制。

行为回归位于 crates/tswn_core/src/runtime/combat/boss/squall_tests.rs，覆盖固定出勤、召唤概率分支、采样、独立连击、强命、属性持久化、红温、暴政、助手与整场快慢执行一致性。

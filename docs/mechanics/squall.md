# Squall 科研 Boss

输入 `Squall@!` 召唤科研 Boss。攻、防、速、敏、魔、抗、智的初始最终数值均为 106，HP/最大 HP 为 360，初始 MP 为 53。速度不追加普通名字的 160 点。图标与 `Squall@Squall` 的 RGBA/PNG 一致。

## 技能与结算

| 技能 | 行为 |
| --- | --- |
| 开始测试 | 自上次自身行动以来有敌方本体行动时，在行动结束获得 1 层测试样本，上限 6；按真实已结算生命损失更新重点研究对象。召唤物不额外提供样本。 |
| 加权平均 | 消耗 2 层样本，进行三次独立魔法攻击，各为普通魔攻的 55%；前两次优先攻击重点研究对象，第三次攻击另一敌方本体；目标死亡后重选。至少间隔 2 次自身行动。 |
| 嘲讽变换 | 交换敌方本体中最高与最低的当前聪明索敌评分，使用临时吸引力覆盖实现。持续后续 2 次自身行动，至少间隔 4 次自身行动；净化关联角色、Boss 死亡或阵营变化会解除。 |
| 现在只有我在做真正的三人科研 | 每场只召唤一次高位辅助和低位配件。各有 43 HP、106 速度和 64 的其他战斗属性。辅助交替铁壁/守护，配件交替弱化群攻/减速；不复制 Boss 被动。 |
| Top50剪枝 | 标记最多 3 名最低生命的敌方召唤单位，下次真实行动开始对每个目标进行 200% 普通魔攻。冰冻推迟结算，净化可以解除标记，结算时重新检查存活和阵营。至少间隔 3 次自身行动。 |
| 蓄力铁壁 | 当前行动后及后续 2 次自身行动期间，直接伤害减少 40%；下一次攻击伤害提高 50%。至少间隔 4 次自身行动。 |
| 1437大帝·无死角地裂 | 三波群体魔法伤害，每波按原版地裂分摊公式的 60% 结算，各次分别走回避、防御、护盾、反弹和死亡链；至少间隔 4 次自身行动。 |
| 聚气治愈，续航才是王道 | 低于 55% HP 时恢复最大 HP 的 12%（向下取整，初始为 43），解除一个普通负面状态，并积累 25% 下一击增伤；至少间隔 4 次自身行动，每场最多 3 次。 |
| 我说的是20%，不是Top20% | 每成功发动三次主动技能后，下一次主动技能误解需求并取消，占用行动，最多失去 2 层样本。进入[我错了]，至下次行动前受伤增加 25%；第三次成功发动时预告模型即将交付。 |
| 测完1T烧1T | HP 首次降到 25% 或以下时，清空样本，每层永久提高攻、魔 6% 和速 8%，此后停止采样与加权平均。每次自身行动结束损失最大 HP 的 1%（向上取整，初始为 4），可致死，无锁血或额外复活。 |
| 红温 | HP 首次严格低于 50% 时自动进入，不占用行动。攻、防、速、敏、魔、抗、智永久提高 50%（初始 106 → 159），持续整场且不能叠加；不占用普通状态槽，净化无法解除，与烧库倍率叠乘。 |

蓄势只在攻击时兑现，合计倍率上限为二倍；净化可移除科研铁壁和蓄势，但无法解除红温。普通名字不受这些专属机制影响，`Squall@Squall` 仍为普通角色。

## 战报

每次技能发动、独立台词、效果明细分段显示，台词紧接发动行。只有显式标记为 dialogue 的台词使用浅灰色背景，发动与效果日志不描底。伤害、回避、恢复、死亡和召唤均沿用 tswn 的正式事件与实际数值。例如：

```text
Squall开始测试，获得1层测试样本
其实不是判断出来，其实就是测出来的

Squall使用[加权平均]
你这个分数很高，但实际打下来不是这么回事。
Squall消耗2层[测试样本]
目标受到伤害……
```

开始测试的台词从本地聊天记录中的以下五句随机选取，避免连续重复；使用独立的演出随机数，不推进战斗 RNG，也不改变胜负：

- 其实不是判断出来，其实就是测出来的
- 我提一嘴，不要对模型的准确性抱有任何信心
- 我还没有进行漏率的检查
- 只是拟合模型
- 转换不成实际战力的话看着烧心

红温的台词固定为同一份聊天记录中 2026-11-06 00:50:43 的原话“我已经要被 6.1sol 整红温了”，不参与上面的采样。误解需求后的负伤状态名“我错了”同样取自同人 2026-10-29 23:34:03 的原话，与红温区分开。

## 验证

行为测试位于 `crates/tswn_core/src/runtime/combat/boss_squall_tests.rs`，覆盖固定数值与图标、采样上限、台词顺序、真实伤害、嘲讽交换/解除、铁壁/易伤、研究助手、恢复次数、误解需求、烧库自损、剪枝、红温阈值与净化免疫，以及普通回放与不捕获帧的批量结算一致性。新 Boss 的数值仍需后续实战调平。

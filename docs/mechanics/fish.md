# 沙冰鱼（Shabby_fish）Boss

输入 `Shabby_fish@!` 挑战。属性与 Squall 同档：攻/防/敏/魔/抗/智 106、HP 360、MP 53；外显速度 106，实战 266。图标固定用 `Shabby_fish@Shabby_fish`。

## 技能

| 技能 | 行为 |
| --- | --- |
| 净化 | 自带 200 熟练度的净化。 |
| 魔高 | 随机两名敌方角色魔力归零 2 回合，到期恢复原值。 |
| 本来大家各种类型打成一片，沙冰鱼直接吊打 | 对所有敌对角色各进行一次普通攻击。 |

剩余 7 个技能待从群成员 413676978 的发言中挑选后补充。

## 验证

`crates/tswn_core/src/runtime/combat/boss_fish_tests.rs` 覆盖固定数值、图标、魔高与净化熟练度。

## 保留的边界与后续验证

- **口罩传播**：本地原版的近距离接触对口罩改用 `wisdom + 192`，受击接触另有 `c75` 分支。当前 Runtime 接触传播只保留 `wisdom >> 1`，准备模板没有通用武器名。后续应先确定如何传递口罩标记，再分别验证两条传播路径；本轮不新增武器载荷字段。
- **回放载荷**：原版灭霸灰烬帧保存旧 HP→0，响指起手没有目标；交换和子体展示也有原版专用字段。当前 [RunUpdate](../../crates/tswn_core/src/runtime/update.rs) 未投影等价的逐事件血量载荷。保留现有接口，不能由这些展示差异推断战斗胜负不同。
- **待证实的复合路径**：原版生命之轮在执行时重验差 64，只按 charge 状态偷行动值；Rust 在准备时选敌，并兼容三倍攻击倍率。当前未找到标准对局中准备和执行之间变更 HP、或非 charge 的三倍倍率导致偷条的例子。还可复验灭霸抽中已连带死亡的使魔、柯南击杀马里奥后复活、史莱姆在共享伤害中复活的实际整战轨迹。
- **文案**：本地原版懒癌六条跳回合活动文字已经换版；本轮保留现有回放文字口径，不把 UI 对齐当成战斗规则修复。

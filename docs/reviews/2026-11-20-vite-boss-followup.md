- 三条历史压力用例仅终局摘要与最终 RC4 更新：`3v3v3-908ecb326213b7aa` 为 (6,39)→(5,20)，`cqd-p06-t26-r0135` 为 (107,64)→(104,77)，`score-mario-r11350` 为 (55,98)→(54,188)。每条都用原版直接运行核对实际可见批次和 RC4，保留输入、胜队、轮数、总分及非终局摘要。另仅更新懒癌三条活动展示预期。
- 最终矩阵覆盖 13 个 Vite Boss 的 649 场公开对局，全部对齐胜方阵营、可见批次、存活者 HP / 行动条 / MP，以及逐批 RC4 游标与 256 字节置换表指纹（校验 FNV-1a，不把指纹当作逐字节证明）。其中 34 场仍存在规范化战报差异，例如聚气与铁壁占位符、魅惑/疾走自动解除的发帧顺序；不是战斗状态或随机流差异。
- 区分战斗数据与浏览器表现：核心不输出原版 HTML/资源、不替换现有播放速度策略。通用解除状态事件的可空施法者和部分延时、旧 API 数值格式等不作为 Boss 战斗规则差异。角色/队伍之外的通用输入语法和核心扩展指令也不拿来宣称原版等价。
- 验证：nightly 格式检查、离线工作区全量、124 条冻结对局、WASM 目标检查与前端 Node 测试均通过。

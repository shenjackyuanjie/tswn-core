## 7. 复测命令

```powershell
# 构建（如本机 sccache 包装 C 编译失败，追加 --config "build.rustc-wrapper=''"）
cargo build -p tswn_core --release --features no_debug --example perf_runtime

# 单线程 10 轮，逐轮落盘
$dir = 'target/fixed30_2026-11-18'
foreach ($i in 1..10) {
  Start-Sleep -Seconds 3
  target\release\examples\perf_runtime.exe -i docs\perf\fixed_cases_30 -n 13000 --threads 1 |
    Out-File "$dir/t1_r$i.jsonl" -Encoding utf8
}

# 自动线程
foreach ($i in 1..10) { target\release\examples\perf_runtime.exe -i docs\perf\fixed_cases_30 -n 13000 --threads 0 | Out-File "$dir/t0_r$i.jsonl" -Encoding utf8 }

# init/fight 分解
target\release\examples\perf_runtime.exe -i docs\perf\fixed_cases_30 -n 13000 --threads 1 --timed
```

摘要方法：每轮 `sum(elapsed_seconds) / sum(total)` 得到 µs/场，跨轮取中位数；离散度用 CV 与 `3 × 1.4826 × MAD` 判定离群轮。原始逐轮数值见 JSON 的 `rounds`、`groups`、`cases` 字段。

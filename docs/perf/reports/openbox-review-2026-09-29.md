# Openbox 代码与性能检查（2026-09-29）

性能基线 `1dc2b216`，吞吐与内存对照候选为 `823bcd43`；后续模块拆分、测试精简与界面说明/配色以回归和原生截图验证。最终代码为 `f45b6c6e`。本轮检查覆盖 GUI 状态与渲染、日志收件箱、
四个后台入口、矩阵调度、文件输出、预设加载、技能榜、CLI 参数与事件转发，以及截图和性能探针。
按已确认的问题修改，没有调整战斗语义、线程默认值、视图选项顺序或文件格式。

## 问题与处理

| 问题 | 处理 |
| --- | --- |
| 每次明细更新都会重建整个显示行索引，表格选中项逐帧排序 | 折叠卡片和表格的数值变化不再重建行索引；缓存明细顺序，只对变化项重新排序；Top 只排序入选部分 |
| 技能榜展开后每帧扫描、拼接并布局全部日志 | 为技能榜维护随裁剪同步更新的索引，只布局可见行 |
| 实时观察入口仍生成随后丢弃的旧日志 | 在格式化之前跳过旧日志；实时批量路径不再保存重复的靶子文本，导出和 pair 路径也跳过无用文本 |
| 文件排序在比较器中反复解析数字或 JSON，并再拼接整份文件 | 提取 output 模块，每行只解析一次分数，缓冲写回已排序行；同分及无效行排序规则不变 |
| cqd/cqp 一次构建完整选手×靶子请求矩阵 | 提取 batch 模块，以 4096 个矩阵位置为一个窗口；镜像仍先累计，再按原靶子顺序累计实际对局 |
| 每组对局重复解析镜像身份，pair 每个靶子重建组合文本 | 缓存输入身份及当前队伍文本，准备请求阶段检查取消 |
| 文件预览读取并扫描整个文件，渲染时再次克隆 | 预览最多读取 16 KiB 加一字节截断标记，展示前十行；运行时仍读取并验证完整输入 |
| 四个 GUI 入口重复创建线程、捕获 panic，线程创建失败会 panic | 共用带名称的任务启动方法，统一将创建失败和计算异常转换为可见错误 |
| CLI 非负阈值接受 NaN/无穷值；存在重复标签和无用代码 | 拒绝非有限值，复用指标名称，无 BOM 输入不复制全文；旧串行基准仅用于测试，清除 Openbox 警告 |

预设释放、帮助与参数控件没有逐帧磁盘扫描；已有按需刷新与配置解析保持原状。
输入、CLI 兼容日志、排序文件仍可能随总输入增长；窗口预算只约束在途请求，不是进程内存硬上限。
没有引入共享全局玩家缓存，以免高唯一度输入再次累积常驻内存。

## 模块结构与界面收尾

原 `backend/tasks.rs` 按工具拆为 `to_diy.rs`、`namer_pf.rs`、`batch.rs` 和 `pair.rs`，
`pair/matrix.rs` 只负责矩阵调度。公共评分参数与分数类型归入 `score.rs`，文件操作归入 `output.rs`，
输出规则和共用技能名称归入 `format.rs`。导出测试单独存放，其他回归随业务模块迁移。
`backend.rs` 保留原来的公开导出，GUI、CLI 与 probe 不需要适配新路径。

GUI 的 `actions.rs` 负责校验和组装输入，`task.rs` 负责线程生命周期与收件箱消费；
`results.rs` 管数据、索引和裁剪，`results/view.rs` 管结果绘制，`style.rs` 集中维护深浅主题配色。
没有引入额外服务层或接口抽象。

四页增加输入、评分、阈值和导出说明；运行、停止、复制、清空提供悬停提示；
结果区增加可固定的说明窗口与状态图例。工具、状态和重点结果以颜色区分，同时保留文字。
浅色截图：[卡片](../../images/openbox-live/cards-light.png)、[表格](../../images/openbox-live/table-light.png)。
截图功能仍默认关闭，`--capture-light` 仅用于检查浅色主题。

按使用价值精简 8 项细碎或重复测试：静态文案非空、内部缓存地址、仅验证简单替换或测试专用函数的断言已移除；
非有限阈值检查并入既有 CLI 参数校验。保留能发现并发归属、格式兼容和大输入问题的回归，UI 文案与配色通过截图检查。

## 同机交替对照

Windows / Ryzen 7 5800X，workspace 原有 release 配置（fat LTO），8 线程，全部明细，实时观察入口。
每组预热一轮，随后交替运行三轮取中位数。候选和基线使用同一份 Core、同一输入与编译参数。
耗时包含后台计算、实时收件箱和 100ms 消费者，不包含 GPU 呈现或最后一次消费者等待。
内存通过 psutil 每 10ms 查询进程报告的峰值工作集 `peak_wset`，与上次报告的结束 RSS 不同。
短时样本仍有调度噪声，负差异不作为加速保证。

原始轮次、程序 SHA-256 和 stdout 对照哈希见 [JSON](openbox-review-2026-09-29.json)。

输入沿用 [实时日志验证](openbox-live-2026-09-29.md)：pair 取该报告中的三组派生文件；
cqd/cqp 使用 `probe0@red` 至 `probe4999@red` 的前 N 行，靶子为 `assets/targets/target2.txt` 前 N 行。

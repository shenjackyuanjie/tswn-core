# 普通技能的 Clever 决策评价

本表覆盖 25 个普通主动技能、10 个普通被动技能，以及召唤物的自爆、附体动作。所有 +武器及其专属动作均排除，包括死亡笔记、剁手刀、玄月、冰河时代与尤里控制。武器原有正式战斗兼容逻辑保留，本次不增加其候选、估值规则或专属用例。

## 共同口径

主动技能先通过原资格判定，再枚举目标，调用正式引擎结算整个回合及后续战斗。即时伤害、治疗、MP 消耗、被动触发、召唤、技能熟练度衰减均由真实结算体现，不为每个技能另加一个固定奖励。技能是否值得用取决于相同独立模拟种子下的终局结果及未结束局面的资源差。筛选、采样与战术续局预算仍为原来的 16 samples / 128 horizon / 4 shortlist；局部潜行兑现最多额外跟进 32 个调度轮。

下表的“残值”只指试算到达预算边界后仍未兑现的效果，数值是有界启发式，不是胜率。完整伤害公式、命中判定和技能联动以正式引擎为准，估值不读取真实未来 RNG。

## 主动技能逐项评价

| 技能（内部名） | 比较的目标与取舍 | 预算边界的剩余价值 |
| --- | --- | --- |
| 火球术 Fire | 全部敌人；即时伤害、后续火系增伤、是否击倒 | 灼烧层数结合敌方可用火球/地裂和 MP；无相应施压能力时不额外扣血值 |
| 冰冻术 Ice | 全部敌人；伤害与冻结后错失的行动 | 冻结压低行动能力，并有界计入剩余冻结量 |
| 雷击术 Thunder | 全部敌人；逐击命中、伤害、击倒与反击风险 | 剩余 HP、存活人数及正式触发的状态；不重复添加连击伤害 |
| 地裂术 Quake | 每个敌人均可作首目标，后续采用低血与高输出队列 | 实际群体伤害和火系状态；不把候选列表当作全部必定命中 |
| 吸血攻击 Absorb | 全部敌人；伤害与实际回血、过量治疗损失 | 施法后实际 HP，不额外添加吸血奖励 |
| 投毒 Poison | 全部敌人；即时攻击和延后毒伤 | atp 是总毒量，按正式公式分摊最多三跳；计入目标魔力减伤、逐跳取整、后续跳折扣及当前 HP 上限 |
| 连击 Rapid | 全部首目标和最多三个有效目标的两种顺序 | 各目标实际结算后的资源，不把额外列表项重复计伤 |
| 会心一击 Critical | 全部敌人；实际伤害、击倒与被动链 | 实际 HP 和存活状态 |
| 瘟疫 Half | 全部敌人；当前 HP 比例、抗性、闪避及蓄力联动 | 按实际剩余 HP，保留其不能凭空当作必杀的结算结果 |
| 生命之轮 Exchange | 常规比较 HP 更高的敌人；蓄力时比较全部敌人，允许牺牲 HP 换行动条 | 交换后的双方 HP、己方获得与对方失去的行动条 |
| 狂暴 Berserk | 全部敌人；即时伤害及强制物攻、随机目标、失去选技的利弊 | 按物理输出而非魔法输出估计强制行动，结合剩余持续时间 |
| 魅惑 Charm | 全部敌人；当前控制权、后续行动与原阵营恢复 | 按剩余持续时间将 75%～90% 资源暂借有效阵营，余量留给原阵营 |
| 加速术 Haste | 全部存活队友，含自身；输出强度、当前行动条、持续时间 | 实际有效速度、行动条及有界的持续增益 |
| 减速术 Slow | 全部敌人；行动频率和剩余持续时间 | 实际有效速度及有界的持续行动损失 |
| 诅咒 Curse | 全部敌人；即时攻击和未来受击放大 | 六位随机判定对应 prob/64；结合敌方施压和 multiply，限制在当前 HP 内；不降低受诅咒者自身输出 |
| 治愈魔法 Heal | 全部受伤队友；实际回血、解除负面状态、技能衰减 | 更新后的 HP、状态、速度和控制权；满血时正式引擎不能净化，因此不枚举空治疗 |
| 苏生术 Revive | 未消耗的普通友方尸体；恢复生命、行动与熟练度损耗 | 实际复活单位；仍未复活的尸体仅在存活己方可施苏生时保留少量储备 |
| 驱散 Disperse | 全部敌人；攻击与清除蓄力、聚气、铁壁等正面效果 | 用清除后的实际属性及状态评价，不固定奖励驱散次数 |
| 铁壁 Iron | 自身；当前生存、行动条代价、后续潜行能否兑现 | 实际防御/抗性及保护强度、持续时间；真实续局负责伤害阻断 |
| 蓄力 Charge | 自身；消耗本次行动换 MP、攻击倍率及后续技能联动 | 实际 MP、倍率与持续蓄力联动；与聚气叠加仍可区分 |
| 聚气 Accumulate | 自身；攻击倍率、行动条与蓄力联动 | 实际倍率、行动条；倍率用对数压缩，避免极端倍率吞掉其他局面信息 |
| 潜行／背刺 Assassinate | 全部敌人；起手后继续真实推进到背刺、打断、死亡或预算上限 | 按四倍魔法攻击、目标抗性和当前 HP 有界估计；可打断潜行折半；目标死亡不留虚假收益 |
| 召唤 Summon | 自身；生成使魔、额外行动、分摊伤害及所有权关系 | 存活使魔的真实属性、HP 和行动条；不按“召唤次数”另加奖励 |
| 分身 Clone | 自身；新增单位对比本体属性与技能衰减 | 本体和分身分别按真实现状计值，不能仅奖励人数而忽略本体衰减 |
| 幻术 Shadow | 自身；幻影存活、攻击能力、后续行动及技能衰减 | 实际新增实体、属性与状态，所有权变化由生命周期结算 |
| 使魔自爆 SummonExplode | 全部敌人；爆炸伤害对比牺牲使魔的损失 | 自爆后实体真实死亡，不能同时保留使魔生存价值 |
| 附体 Possess | 全部敌人；施加狂暴对比施法召唤物死亡的代价 | 对目标按狂暴机制评价，并删除死亡施法者的存活价值；不将附体误当作永久换队 |

## 被动技能逐项评价

被动技能不伪装为可自由选择的主动候选。每个主动候选的正式续局都会执行这些技能的资格、MP 消耗、触发顺序与结果。

| 被动技能（内部名） | 决策中如何衡量 |
| --- | --- |
| 防御 defend | 正式防御链中的触发和减伤改变实际 HP；通过不同攻击目标和攻击方式比较其代价 |
| 反弹 reflect | 正式反弹伤害和反向击倒计入结果，避免只看目标掉血 |
| 守护 protect | 正式拦截与守护者承伤均结算；边界处仅给仍存活同队守护关系少量残值 |
| 护盾 shield | 正式护盾阈值和消耗决定挡伤；边界处按剩余护盾有界计值，不当作额外完整 HP |
| 垂死 upgrade | 正式触发和清除改变当前攻击、防御、敏捷与速度；直接评价更新后的属性 |
| 隐匿 hide | 正式触发和下次行动前解除保留；边界处结合真实防御属性及少量隐匿残值 |
| 反击 counter | 正式 update-end 执行反击；仅在待反击目标仍有效时保留少量物攻残值 |
| 吞噬 merge | 正式击杀链更新属性、技能与尸体消耗，评价变化后的实体；尸体被吞噬后失去苏生储备 |
| 亡灵 zombie | 正式死亡与召唤生命周期生成亡灵、消耗尸体并处理所有权；按结果中的真实实体评价 |
| 重生 reraise | 正式死亡链处理重生、消耗与恢复的 HP；不把概率重生预先当作确定多一条命 |

## 本次验证边界

本机验证：核心单元测试 878 项、CLI 集成测试 91 项、其余适用集成/doctest 通过；其中搜索模块 23 项。WASM 原生测试 12 项、前端 Node 测试 61 项通过。未新增契约测试。

搜索模块遍历 25 个普通主动技能及两种召唤物动作，调用正式执行器并检查实际伤害、HP 交换、恢复、状态、蓄力、聚气或潜行登记。另有目标枚举、持续状态、毒量/减伤、灼烧/诅咒施压、背刺抗性/打断、蓄力生命之轮行动条交易，以及铁壁到背刺的正式结算回归。上述用例验证机制和估值方向；总体评分提升仍需独立名字集合的四模式配对评测。

# tswn_core 0.6.0 更新说明

> 发布日期：2026-09-08。本文件记录从 0.5.3 到 0.6.0 的正式更新、迁移要求与验证结果。

## 版本定位

0.6.0 将交互式回放、流式输出和模型数据生成统一到同一套 BattleSession 推进语义，并冻结跨语言 DTO 与错误分类。由于 CLI 删除并迁移了旧入口，Rust 公开错误枚举也发生不兼容调整，本轮按 0.x 约定步进 minor，而不是继续发布 0.5.x patch。

## 迁移说明

### CLI

- `tswn-cli raw` 已删除；普通对战使用 `tswn-cli fight`，逐帧机器可读输出使用 `tswn-cli fight --jsonl`。
- `tswn-cli diff` 已迁至 `tswn-cli runtime diff`。
- `tswn-cli fight --out-raw` 已删除；调用方应迁移到 `--jsonl`，并按 `initial`、`frame`、`result` 记录处理输出。
- `!test!` 不再自动切换特殊 benchmark 路径；性能与批量入口统一放在 `bench` 子命令下。

### Rust API

- `CliApiError::Runner` 更名为 `CliApiError::RunnerInit`；同时新增 `InvalidArgument`、`UnsupportedOption` 和 `Internal` 分类。穷举匹配该枚举的调用方必须更新分支。
- 新的 `BattleSession` 提供初始状态、逐帧推进、当前快照、完成结果、停止原因和稳定错误码。`is_failed()` 专门表示粘性 Runtime failure；失败会话没有 result/stop_reason，且 `is_done()` 保持 false。
- `BattleModelSession` 与 `runtime::model_state` 面向无界面数据生成，导出只读类型化机制状态、技能映射、实体引用和召唤蓝图，不构造回放 DTO、图标或展示快照。
- `cli_api::to_diy_prepared()` 可以直接导出已经构建的 `PreparedPlayer`，避免重复解析和构建。

## 跨语言会话

- C API 在 ABI 4 下新增 BattleSession opaque handle、版本化 options、逐帧/快照/result JSON 和状态查询；V1 prefix 永久冻结，旧初始化函数只写 V1，现有 ABI 版本不变。
- Python 新增 `BattleSession` PyClass、迭代器和精确 TypedDict，并让异常携带统一错误码。
- WASM 新增 canonical `BattleSession` 与 plain JS/TS DTO；旧 `FightSession` 保留为兼容包装。show 页面改为真实 streaming、两帧预取和可恢复的逐帧历史导航。

## 正确性修复

- 批量胜率不再使用 legacy 粘性存活组计数判定完成；某队被清空后重新复活时，胜者与全量扫描路径保持一致。名字池 10,000 局中的该类差异由 2 局降为 0。
- replay view 在苏生帧先固定重置为 `0 -> 0`，再从 0 推演回复，避免动作前 HP 泄漏到复活句。
- 亡灵转化句分别输出旧对象与新对象的 player part，恢复普通名字与结构化文本语义。
- WASM 兼容会话保留直接 `owner_id`，不再错误替换为 root `source_id`；canonical TypeScript 枚举收紧为实际输出的 literal union。

## 性能与工具

- 受伤被动技能计划复用固定容量缓冲，减少常见战斗热路径的临时堆分配。
- 新增 `perf_runtime` 基准入口、AMD uProf 采样流程和流式页面阶段计时；`no_debug` 发布路径不编译诊断分支。
- 新增 `tswn_winprob_dataset` 0.1.0 初始工具，用同一模型会话生成、续跑、验证和统计嵌套 Parquet 数据集；该工具不进入默认 `build_all.py` 聚合包。

## 发布验证

本轮已执行并通过：

```powershell
cargo +nightly fmt --check
cargo test -p tswn_core
cargo test --workspace
cargo clippy --workspace --all-targets
python scripts/check_runtime_release.py
python scripts/verify_py_cli_api.py
python scripts/verify_battle_cross_binding.py
python scripts/verify_battle_docs.py
python scripts/build_all.py --release -o target/codex_release_final
```

Windows 与 Linux 的 `tswn_py 0.5.3` wheel 均已重新构建，并在独立 Python 3.12 虚拟环境中完成安装与导入验证。聚合脚本已确认跳过残留的 0.5.2 wheel，只收集当前版本产物。Rust CLI、Python、C 与 WASM 在四组 fixture 的完整/限轮设置下逐字段一致；公共 API 文档示例也已实际执行。

默认 release 聚合包包含 `tswn_core 0.6.0`、`tswn_capi 0.6.2`、`tswn_py 0.5.3`、`tswn_wasm 0.5.4` 和 `tswn_openbox 0.4.3`。OHOS 与 PGO 产物仍按发布目标显式启用，不属于默认构建。

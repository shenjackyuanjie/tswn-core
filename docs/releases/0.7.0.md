## 迁移说明

- `tswn-cli namer-pf` 删除 `--mode`；用可重复的 `--metric` 选择指标及阈值／输出文件。
  默认屏幕输出从管道表改为 `名字组合 指标:分数`，解析旧输出的脚本必须适配。
- CLI 增加技能榜、带权队友、块状明细、输出排序与标签清洗参数；默认关闭的选项保持既有行为。
- Openbox 共用后端迁入 `tswn_openbox_backend`，旧 `tswn_openbox::backend` 与
  `tswn_openbox::presets` 通过再导出保留。DS4 直接依赖共享后端，不依赖 GUI 或外部 CLI。
- C、Python 与 WASM 本轮仅跟进核心实现，不暴露实验性 encoder，也不改变现有绑定契约。

## 主要更新

- FeatureEncoder 提供 manifest 校验、局内引用重映射、八族 69 个张量、presence／mask、
  精确 bit 旁路与可复用批缓冲；编码失败仅清理目标槽位，不污染相邻样本。
- 新增 `runtime_cqp_matchups_observed()`，完整 matchup 汇总后立即在调用线程回调索引与结果。
- PWP 支持 Parquet 数据生成、续跑、校验、统计、标量校准与小端 tensor 离线导出；校准记录来源
  摘要与行选择证据。`encode` 尚会收集所选切分的全部状态，批大小不构成读取阶段的内存上限。
- Openbox 提供增量结果、纯文本／卡片／表格视图、DS4 彩色配置页面与上下文帮助；矩阵、预览、
  排序和可见行渲染均采用有界或缓存路径，避免大输入下重复构建与绘制。
- DS4 保留 ABCP5 历史缓存、降线程重试与三轮实战筛选；外部模型／程序不随 crate 分发，
  当前全流程不支持取消，同一工作目录不能并发运行。

## 分发边界

本轮使用仓库级 `v0.7.0` tag，在 GitHub 与 Gitea 发布相同的 Windows x64 产物；不上传
crates.io 或 PyPI。聚合 ZIP 包含 C API、CLI、Python 3.12 wheel、WASM、Openbox GUI 与
`openbox-cli`。三个 EXE 同时作为独立附件上传，与 ZIP 内的二进制逐字节一致。

附件包括：

- `tswn-core-v0.7.0-win-x64.zip`
- `tswn-cli_alpha_0_7_0.exe`
- `openbox-cli_alpha_0_4_6.exe`
- `tswn_openbox_alpha_0_4_6.exe`（Openbox GUI）
- `SHA256SUMS.txt`

PWP、DS4 独立 CLI、ranker 和 ladder 不加入默认聚合包。name ranker 的两份独立校准数据
`abcp_directional_calibrator.json` 与 `abcp_calibration_features.tsv` 在本机缺失，无法编译，
本轮仅归档源码版本，不提供其二进制，也不将其计入 workspace 验证通过范围。
